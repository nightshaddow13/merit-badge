Hash Lab

A SHA-256 fingerprint tool. Works offline in any browser. Nothing you type leaves this device.

Try "Warden", then "warden", then "Warden!" Notice that a tiny change makes a completely different fingerprint. The yellow part is the first 8 characters: the short version we compare in class.
File integrity check: if the two fingerprints match, the message was not changed. If they differ (red characters), it was changed.
Type the text and the posted checksum
Match means untouched. No match could mean the document was tampered with, or you made a typo. Check the character count against your card, then decide.
Make a copy of a file, change one thing in the copy, hash both, and compare. Same file, same fingerprint.
